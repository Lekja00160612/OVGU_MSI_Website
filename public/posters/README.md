# Posters & Event Media (`/posters`)

This directory contains print-ready vector PDF files and web-resolution PNG posters for MSI academic workshops, seminars, and recruitment fairs.

---

## File Inventory

- `msi-seminar-workshop-2026.pdf` — High-resolution print-ready vector PDF poster for the 2026 International Seminar & Workshop.
- `msi-seminar-workshop-2026.png` — High-resolution 300 DPI image poster for digital display, social media, and web promotion.

> Note: The source code for generating this poster is written in Typst and located at `posters/msi-seminar-workshop-2026.typ` in the repository root.
