## Conventions for New Avatars

- Aspect ratio: Square or 4:5 portrait
- Dimensions: Minimum 400x400px (retina-ready)
- Format: JPG, PNG, or WebP
- Filename format: `[Firstname Lastname].[ext]` (matches lecturer name in metadata)
